# Coentro
A cohesive and animated epub reader for Edge.

Easily read your books using Coentro seamlessly. It allows you to apply Read aloud and Continue reading aloud from here on Edge. 
You also can modify the positions on the Library.
And yet, you can use regular expressions on Search.
